# PiPal Roadmap

## Vision

PiPal is an AI-native STEM Operating System that helps students imagine, build, wire, code, learn, and iterate on physical computing projects.

PiPal combines:
- Coding Companion
- Wiring Companion
- Learning Companion
- Project Memory
- Curriculum Progression

into a single guided maker experience.

---

# Phase 1 - Foundation (Current)

Goals:
- Multi-user support
- Student/Admin roles
- Project workspaces
- Curriculum framework
- Hardware awareness
- Basic code companion
- Basic wiring companion

Status:
In Progress

---

# Phase 2 - Persistent Project Memory

Goals:
- Project memory persistence
- Conversation history persistence
- Code history tracking
- Wiring history tracking
- Resume previous projects

Success Criteria:
Student can return to a project weeks later and PiPal remembers previous work.

---

# Phase 3 - Guided Learning Journey

Goals:
- Learning paths by level
- Project recommendations
- Challenge progression
- Skill tracking
- Curriculum completion tracking

Success Criteria:
PiPal can guide students from beginner to advanced projects.

---

# Phase 4 - Visual Wiring Companion

Goals:
- Breadboard visualization
- GPIO diagrams
- Wiring validation
- Component placement guidance

Success Criteria:
Students can see and understand physical wiring visually.

---

# Phase 5 - Runtime Execution

Goals:
- Run code
- Stop code
- View logs
- Error analysis
- Debugging support

Success Criteria:
PiPal can help students execute and debug projects.

---

# Phase 6 - STEM Learning Intelligence

Goals:
- Adaptive teaching
- Personalized recommendations
- Learning analytics
- Reflection questions
- Creative project suggestions

Success Criteria:
PiPal behaves like a long-term STEM mentor.
